2. 감점 요소 (사진 포함)

① APK 미제출 −1.5 (8번)

제출 폴더 어디에도 Module_A_XXX.apk가 없다. 소스 루트 제출, 파일명 규칙, 제공된 APK로 평가 세 하위 항목(각 0.5)이 모두 미충족이다. 이번 채점은 원본을 건드리지 않고 복사본에서 flutter build apk --release로 직접 빌드해 실행했다.

※ 대회에서는 APK가 열리지 않으면 채점 불가(0점)이므로 가장 위험한 항목이다.

확인 위치
2026-reg-lyj/ 루트·build/ 내 APK 없음

② 시작하기를 눌러도 홈으로 이동하지 않음 −0.6 (22번)

정보 확인 화면의 시작하기 버튼이 print('클릭됨')만 실행한다. 홈(빈 화면)으로 이동하지 않아 요구사항 3번과 4번이 모두 미충족이다. 빈 홈 화면용 BlankHome 클래스는 만들어 두었지만 어디에도 연결되지 않았다.

위치: lib/main home/flows/info_field.dart 의 ConfirmField.start()(약 729행)

③ 온보딩 애니메이션이 2초를 넘는다 −1.2 (10번)

구름 0.9~1.4초, 달 1.7~2.7초, 로고·문구 2.6~3.6초, 버튼 3.5~4.5초에 끝난다. 요구사항은 "달·구름", "로고·문구", "버튼"이 각각 2초 이내에 애니메이션되는 것이다. 시작 후 기준으로 보면 세 항목(각 0.4)이 모두 2초를 넘는다. 시작 후 0.9초 동안은 빈 배경만 보이고 버튼은 4.5초가 지나야 누를 수 있다.

※ "애니메이션 1개가 2초 이내"로 해석하면(각 1초) 충족이다. 심사위원 합의 사항이다.

위치: home_screen.dart:40-56 (Future.delayed 900ms 간격 4단계)

④ 시간 화면의 이전 버튼 목적지 −0.4 (20번)

채점표 20-5는 "이전 버튼 클릭 시 성별 선택 화면으로 이동"이다. 앱은 날짜 화면으로 이동한다 (캡처 46). 과제 문서의 오타일 수 있어 심사위원 확인이 필요하다.

위치: home_screen.dart:286 모든 단계에서 pageIndex--

⑤ 시간 화면 안내 문구의 마침표 누락 −0.2 (19번)

과제는 "태어난 시간을 입력해주세요."인데 앱은 마침표가 없는 "태어난 시간을 입력해주세요"이다. 다른 화면 문구는 모두 마침표가 있다. 경계 사례이며 엄격한 기준으로 감점했다.

위치: home_screen.dart:32 texts[5]

⑥ 주관 항목에서 점수가 깎인 곳 (주관)

  • 화면 전환 중 글자가 겹친다. 이전·다음 화면의 문구와 placeholder가 겹쳐 뭉개져 보인다 (전환 캡처 04). (화면전환 5번)
  • 키보드가 올라오면 하단 요소가 위로 튄다. 이전 버튼, 진행 막대, 구름이 키보드 위로 올라간다 (캡처 43). (정보 입력 일치도 2번)
  • 입력창 테두리가 프로토타입보다 굵다. 프로토타입은 얇은 흰색 선이다. (정보 입력 일치도 2번)
  • 나이에 글자를 입력하면 안내 없이 막힌다. "숫자만 입력할 수 있어요." 같은 안내가 있으면 4등급이다. (친절한 메시지 6번)

3. 코드 리뷰

한 파일에 너무 많은 화면이 있다

  • info_field.dart 한 파일(793행)에 이름·나이·성별·날짜·시간·확인 화면 6개와 UserController, BlankHome이 모두 들어 있다. 어느 화면을 고칠 때마다 긴 파일을 내려가며 찾아야 한다.
  • 폴더 이름에 공백이 있다 (lib/main home/). 공백 경로는 import 문자열과 도구에서 문제를 일으키기 쉬우니 page/, controller/처럼 소문자 스네이크 이름을 쓰자.
  • 온보딩과 입력 흐름이 모두 HomeScreen 한 곳에서 pageIndex로 전환된다. 간단하지만 이름이 "홈"이라 이후 모듈의 진짜 홈 화면과 헷갈린다. 화면 1개 = 파일 1개로 나누자.

사용하지 않는 코드와 디버그 흔적

  • BlankHome은 만들어 두고 연결하지 않았다. 이것 때문에 22번이 감점되었다.
  • home_screen.dart의 nextTo()와 editing 처리는 일부만 쓰이고, 각 필드는 next로 pageIndex를 직접 바꾼다. 하나의 방식으로 통일하자.
  • 시작하기에 print('클릭됨')이 남아 있다. 제출 전에 지워야 한다.
  • 변수명이 섞여 있다 (showmoon은 소문자, showCloud는 camelCase).

라이브러리

  • flutter_svg는 pub.dev publisher가 flutter.dev로 확인되어 허용이다. 그 외 외부 패키지는 없다.
